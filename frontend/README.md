# Holly Frontend

This is the front-end to Holly. It is written using svelte and connects to the django app layer
via a rest api. The Rest API layer is autogenerated using OpenAPI generator based off of the openapi.json that is created as documentation from the Django app. 

nvm is used to ensure we are building from the same node version. To build this run:

nvm use
npm i
npm run api:full  # this will download the latest openapi.json spec and build/install the API client
npm run dev
